# GitHub Workflow Lab

A small, practical repository for learning GitHub's core collaboration workflow:
issues, branches, commits, pull requests, reviews, and merges.

## Learning goals

- Turn a concrete task into a well-scoped issue.
- Isolate changes on a descriptive branch.
- Write a focused commit with a useful message.
- Open a pull request that explains what changed and how it was checked.
- Understand when review is required and how merge strategies affect history.

## Repository structure

- `README.md` explains the purpose of the lab.
- `CONTRIBUTING.md` contains the practice workflow.
- `.github/ISSUE_TEMPLATE/learning-task.md` provides a reusable task template.
- `.github/pull_request_template.md` provides a concise PR checklist.

## Practice principles

This repository is intentionally low risk, but its history should still be useful.
Each issue and pull request should describe a real learning task rather than an empty
or repeated action.
